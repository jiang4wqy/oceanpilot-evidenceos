## 版本与故障检查

自动化交叉验收覆盖关键缺失/普通缺失、来源不明、事实冲突、规则无精确匹配、材料或规则变化后旧审核失效；创建双击及相同命令重放、返回失败后查询回执、持久化重启恢复、跨案件迟到响应丢弃、规则更新期间生成摘要冲突、HTML 输入转义、模型非法动作和越界事实主张降级。摘要只复用同版同规则的已保存分析，没有合适分析时使用确定性快照。

新增复核请求必须同时提供案件版本与 `expected_rule_fingerprint`。旧记录缺少指纹时保留为历史，不能冒充当前复核。规则变更不必改案件版本，也会使旧预览和旧复核失效。

实时验证只使用用户已授权的项目本地凭据，在内存中加载，未输出或提交密钥。除了此前的 1 次最小 Copilot 连通测试，本次追加 1 次完整页面 Agent 请求。它们证明本轮连通和输出边界，不能证明长期可用性或真实业务准确率。

工程验证见 [工程报告](engineering-validation.md)：全量 1429 通过、6 跳过；最终措辞后 41 项页面回归通过；lint/格式和 wheel 内容核对通过。跳过原因逐项记录，未用离线结果替代真实模型测试。
