# 双端逐键与双语验收 · 2026-09-07

本次检查覆盖 `/demo` 商户端、`/business` 企业端。逐项盘点了现有页面的 **38 个按钮处理函数**，并检查导航、筛选、语言选择、文件名输入与折叠区域。验证方式在下表区分：**浏览器**表示在 Codex 内置浏览器通过真实后端实点；**自动化**表示执行打包的原始 JavaScript 或后端集成测试。没有声称每个异常分支、每个重复行按钮都单独手点。

## 结果与修复

- 修复异步文本、占位符、标题和无障碍标签的翻译遗漏；中 → 英 → 中切换不会恢复旧版本文本，也不重建表单或清空尚未提交的选择、疑点处理说明和复核草案。
- 补齐规则目录/详情、材料用途、下一步、疑点、复核、回执、重试、执行记录及下载提示；清理中文模式中的英文界面标题和状态枚举。
- 双端共享语言偏好；跳转同一案件时保留案件与分区。内置 A/B/C 模板名称和说明随语言显示。自由录入文本、文件名、原始文档名及历史模型回答保留原文；历史回答明确标注，可显式重新分析。
- 实时模型请求收到 locale；英文模式提示词不再要求中文，离线/异常降级也提供英文说明。实际页面英文问答返回 `MODEL`，按钮恢复可用。异常重试保留原问题，版本变化后拒绝重放旧问题。
- HTML 下载按所选语言显示，来自同一已冻结快照，不重新调用模型。伴随 JSON 保持原始字段、审核意见、规则指纹及案件版本，不为了语言切换改写数据。历史中文摘要也能从自身冻结快照生成英文展示。
- 对齐案件名称 100、复核意见 1200、来源 120、文件名 180 的后端长度边界；疑点来源为空先在表单拦截，结构化 422 不再显示 `[object Object]`。
- 登记完成后禁用文件/来源/占位文件按钮，避免出现“可点击但不处理”的状态；弹窗增加背景 inert、Tab/Shift-Tab 焦点循环和关闭后的焦点恢复。
- 英文关键词可搜索中文规则名称；筛选清除旧规则详情时同步清除地址里的旧 rule 参数。新建案件默认落在概况页。
- 卡组织按钮改为“提交卡组织选择”，说明已有选择的变更须企业复核；采纳建议前保留原规则，采纳后按实际选择重新匹配。
- 本地维护中心恢复在 8003 运行，读取 8026 服务；最终发送仍由后端禁用，规划入口保持禁用。
