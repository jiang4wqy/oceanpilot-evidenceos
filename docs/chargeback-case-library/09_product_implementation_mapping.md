## 三、生产落地注意事项

1. **时限参数化**：Visa 天数缺失（CONFLICT-012）→ 以收单机构收到的有效版本为准，禁止套用 Mastercard 天数。
2. **编码合并映射**：Mastercard 淘汰码（4855/4841/4860/4859/4831 等）→ 支持旧码→新码映射表，带版本与生效日期（CONFLICT-005）。
3. **多对多映射**：ODPM 原因 × 卡组织编码保持多对多，不强行一对一（CONFLICT-014/015）；BNPL/DCB 渠道单独建分支。
4. **不展示胜率**：只展示证据完整度；胜率仅可用自身历史案件数据估计（GAP-007）。
5. **脱敏**：支持文档 PAN 仅后四位、无涉性内容（SRC-02 通用规则）。
6. **审计**：提案、确认、提交、重试、越权全部留痕。
