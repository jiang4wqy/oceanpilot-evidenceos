# OceanPilot 导师业务验证与数据交接手册

> 负责人任务：用一次 30 分钟访谈确认项目是否切中 Oceanpayment 的真实拒付工作流，争取拿到最小脱敏规则集。不要索取真实卡号、订单、聊天记录或系统权限。

## 你要完成的结果

不是让导师笼统评价“项目好不好”，而是拿到以下四个可验证结论：

1. **问题是否真实**：目前最耗时的是找资料、判断理由码、整理申诉包，还是跨团队催办？
2. **流程是否正确**：拒付通知到达后，谁接收、谁补证、谁审核、谁提交、谁记录结果？
3. **最小规则集**：最高频的 5–10 个卡组织理由码，分别需要哪些证据、由谁负责、多少天内处理。
4. **价值如何衡量**：当前单案耗时、补问轮次、按时提交率、申诉成功率中，哪两个指标最重要？

## 第一个问题（直接照着问）

> 老师，我们现在把项目收窄到“跨境拒付申诉的证据整理与协作”。想先确认真实工作里，从收到拒付通知到提交申诉，最耗人力、最容易出错的一个环节是什么？能否请您按实际顺序讲一笔典型案件，不需要任何客户或交易信息？

这个问题比“我们应该吹概念还是做落地”更有效，因为导师的回答会直接决定演示主线和下一轮开发优先级。

## 30 分钟访谈顺序

### 0–8 分钟：还原一笔典型案件

- 拒付通知最先出现在哪个系统、由哪个岗位看到？
- 通知中通常已有：卡组织、理由码、金额、截止时间中的哪些信息？
- 哪些材料掌握在 Oceanpayment，哪些必须向商户索取？
- 材料整理完成后由谁审核，又通过什么渠道提交？
- 申诉结果回来后记录在哪里，是否用于复盘？

### 8–18 分钟：验证 OceanPilot 的切入点

- “缺什么证据先补什么”是否比直接让 AI 判断原因更符合实际？
- 系统给出责任团队和截止时间，是否真的能减少转派和逾期？
- 哪些动作必须人工确认？哪些内容即使 AI 很确定也不能自动做？
- 当前演示中的七类理由是否覆盖主要场景？缺哪一类？

### 18–25 分钟：争取最小脱敏数据

按优先级请求，不要求导师当场给文件：

1. 最高频 5–10 个卡组织理由码到项目七类理由的映射；
2. 每类理由的证据清单、责任团队和内部处理时限；
3. 若允许，提供聚合数字，例如“证据齐备/不齐备时的成功率区间”；
4. 若文件不能外发，请导师只对我们的合成模板做“正确/错误/需修改”标注。

模板位于 [`docs/data/templates/`](templates/)。所有示例都是合成数据。

### 25–30 分钟：确认下一步

- 谁是规则口径的最终确认人：风控、拒付运营、支付产品还是合规？
- 哪种交付方式符合公司要求：只口头确认、公司内网表格、聚合数据或完全合成规则？
- 约定下一次确认的范围和时间，不要求生产接口或系统权限。

## 会后你要带回来的五句话

把导师原话整理为以下格式，只记录业务规则，不记录客户信息：

```text
1. 当前最痛的环节是：__________
2. 一笔案件的真实责任链是：__________
3. 最高频理由/场景是：__________
4. 最重要的两个指标是：__________
5. 公司允许提供的数据等级是：仅口头 / 合成 / 聚合 / 脱敏规则表
```

## 收到文件后的本地校验

安装项目后，在公司允许的隔离环境运行；命令只输出通过数量，不回显原始记录：

```bash
oceanpilot-validate-data \
  --reason-code-mappings docs/data/templates/reason-code-mappings.example.json \
  --reason-policies docs/data/templates/reason-policies.example.json \
  --bank-rules docs/data/templates/bank-rules.example.json \
  --case-samples docs/data/templates/case-samples.example.json
```

预期输出：

```json
{"status": "ok", "validated": {"bank_rules": 1, "case_samples": 1, "reason_code_mappings": 1, "reason_policies": 1}}
```

校验失败只返回固定错误，不显示原始数据。真实/脱敏文件不得提交到 Git、公开聊天、公开网盘或比赛仓库。

## 不能承诺的内容

- 目前没有接入 Oceanpayment 生产数据或真实拒付渠道；
- 合成规则不能代表真实 Visa、Mastercard 或银行政策；
- 当前“成功概率”只能作为演示指标，未获得公司样本校准前不能声称业务准确率；
- OceanPilot 只整理证据和给出建议，不自动退款、放行、提交申诉或裁决结果。
