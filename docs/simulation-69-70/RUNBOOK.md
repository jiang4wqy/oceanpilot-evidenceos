# 本机合成拒付演示

最初交付基线为 222e754，来源分支为 member-b/synthetic-intake-69-70；以下工作树、实例与端口记录用于追溯 Member B 的验收环境。整合进入主线后，应以主线实际提交号与部署环境为准。

## 启动与恢复

在本工作树中运行（本机复用原工作树已安装的 Python 环境）：

```sh
PYTHONPATH=src ../oceanpilot-member-b-64/.venv/bin/python scripts/member_b_demo.py start --instance work/simulation-demo
```

当前默认离线模型、Mock 上游，不启动飞书。其他机器请从 pyproject.toml 配置自己的 Python 环境，再使用自己的 python 路径。私有账号由 new 生成，保存在实例目录 private-accounts.json，不上传。

停止时仅对本实例进程发送 Ctrl-C；关闭其页面长连接后重启。源代码变化时先验证，再执行同脚本的 pin --instance work/simulation-demo。不要忽略构建身份不匹配。

新一轮演示使用 new --instance work/simulation-demo-next --port 一个已确认空闲端口，保留旧目录；不直接删库或伪造重置。backup/restore 使用脚本的 --destination 新目录，恢复前停止该实例，勿覆盖现有目录。超时后在同一账号重新打开模拟入口，使用保留的原请求继续核对；不要换 request_id 重新建案。服务端保存请求快照及稳定命令，已完成步骤可重放；过期的未完成请求需运营人工核对。

## 录制步骤

1. 打开 http://127.0.0.1:8016/v2/login，进入 OceanPayment。
2. 案例库选 CB-CASE-060 或 CB-CASE-061，点击“用此案例模拟拒付”。填写授权范围内商户、金额（最小货币单位）与币种。
3. 使用有目标商户权限的风控经理账号，预览材料与合成期限并明确勾选确认。系统接收事件、新建空证据案件、登记经理确认的演练规则并发布商户任务。风控专员账号建案后需由经理另行确认规则，不会直接发布待办。
4. 退出并进入商户端，在待办打开新案件。选择接受拒付或提出抗辩，自己填写原因并确认。抗辩后显示商户材料清单及 OceanPayment 应补充的系统材料。
5. 用真实上传控件上传文件。上传不是审批，后续仍由处理团队核验。
