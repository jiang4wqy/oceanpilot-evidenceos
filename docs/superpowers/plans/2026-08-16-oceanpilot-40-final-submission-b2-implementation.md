# OceanPilot 40 强完整方案与 B2 协作台极速实施计划

依据：[2026-08-16-oceanpilot-40-final-submission-b2-design.md](../specs/2026-08-16-oceanpilot-40-final-submission-b2-design.md)

## 成功标准

1. 生成一份可直接用于官方飞书模板的完整方案正文，逐项覆盖官方四大评分维度。
2. 当前能力、下一阶段能力和试点目标严格分层，不保留旧开题材料的过时状态。
3. 提供两张中文对比图的明确插图位置、图注和生成 Prompt。
4. 准备 B2 多维表格主表、三个 Synthetic 案件、五个视图、两个 AI 字段和三条自动化说明。
5. 尽可能在已登录飞书中创建方案副本与协作台；受权限或外部页面限制时，保留可直接导入/粘贴的本地交付物。
6. 不修改现有 Web 主界面，不点击最终提交，除非团队身份、手机号、公开权限和最终内容均已核对。

## 任务 1：生成完整方案正文

- 新增 40 强正式方案 Markdown 单一事实源。
- 填写已知团队、企业、项目、GitHub、实现边界和验证结果。
- 对未知成员分工使用显式“需队长确认”标记，不编造个人履历。
- 覆盖场景、创新、工作流、价值、飞书 AI、体验证据、落地路线和自由展示区。

验证：评分项逐项出现；旧 `501/717` 表述不存在；所有指标标记为试点目标。

## 任务 2：准备 B2 导入资产

- 新增 UTF-8 CSV，包含三个 Synthetic 案件和主表字段。
- 新增 B2 配置说明，记录字段类型、五个视图、两个 AI 字段 Prompt 和三条自动化。
- 所有商户、案件和规则均标记 Synthetic/演示摘要。

验证：CSV 可解析、字段数一致、无真实个人或交易数据。

## 任务 3：飞书方案副本

- 在官方模板中创建副本。
- 设置正式标题。
- 粘贴完整方案正文或建立清晰的可编辑骨架。
- 保留两张图片和 Demo 视频待补位置。

验证：文档存在、标题正确、正文结构可见；最终互联网公开权限在提交前复核。

## 任务 4：飞书多维表格协作台

- 尝试在当前登录租户创建 `OceanPilot｜跨境商户成功案件台`。
- 导入三个 Synthetic 案件。
- 配置可用的视图、AI 字段和自动化。
- 若当前租户权限或浏览器功能阻塞，记录精确阻塞点并交付 CSV/配置说明，不伪装为已完成。

验证：以实际页面为准；方案正文中的完成状态随实际结果调整。

## 任务 5：最终核验

- 对照官方模板与提交表检查必填项。
- 检查 GitHub/测试/CI事实。
- 检查脱敏、公开权限、图片和视频缺口。
- 输出仅需用户本人完成或确认的最小清单。

验证：本地文档通过 `rg` 事实扫描、CSV 解析和 `git diff --check`；飞书提交记录在最终提交前保持可核对。
